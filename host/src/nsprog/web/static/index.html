接线

nsprog 接线表

Tang Nano 9K 的 79–86 脚是 1.8V，不要接。68–75 脚与 HDMI/屏幕座共用，接线时不要插 HDMI 线和屏幕。FT232H 只共地，不接它的电源。

自检结果 排障向导
实时电平
左侧方框是 Tang Nano 9K 排针（按丝印号找），右侧是芯片座 / 模块的引脚。接好一根点一下右边的圆圈打勾，进度保存在这台电脑的浏览器里。
逐根检查
“闪烁”会让那一根线每秒翻转两次（其余引脚释放）：用万用表或 LED 在座子对应脚上找到它就说明这根线通了。“实时电平”打开后，用一根接 GND 的杜邦线碰上拉的座子脚（接 3V3 碰下拉的脚），对应那一行会亮起来。
