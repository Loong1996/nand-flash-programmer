# 04 原型接线与首次调试（Tang Nano 9K + TSOP48）

> 本文引脚分配为**草案**。接线前务必对照 Tang Nano 9K 官方原理图与 W29N02KV 数据手册核对。

## 1. Tang Nano 9K 排针（依据 LiteX `sipeed_tang_nano_9k.py`）

排针上的编号为 **FPGA 封装引脚号**（约束文件使用），物理位置以板子丝印为准。`-` 为电源/地。

```
J6: 38 37 36 39 25 26 27 28 29 30 33 34 40 35 41 42 51 53 54 55 56 57 68 69
J7: 63 86 85 84 83 82 81 80 79 77 76 75 74 73 72 71 70  -  48 49 31 32  -  -
```

排针引出的都是 **3.3V bank**；1.8V 的 Bank 3（引脚 3、4、10、11、13–16，LED 和按键）不在排针上，**不要**把 3.3V 器件接到 1.8V bank。

| 引脚 | 板上用途 | 建议 |
|---|---|---|
| 68–75 | HDMI（板上有上拉，官方提示接排针可能工作不正常） | **避开** |

## 4. 上拉电阻与去耦电容

转接座上没有任何元件，直连 FPGA 做实验可行，但要注意：

| 元件 | 不加的后果 | 最低成本方案 |
|---|---|---|
| R/B# 上拉 | 开漏无上拉则浮空，读不到忙/闲 | FPGA 内部上拉（`PULL_MODE=UP`，较弱，多等一会再采样）；或不用 R/B#，改发 `70` 读状态轮询 bit6 |
| 去耦电容 | 读基本正常；编程/擦除时可能偶发失败，难排查 | **100nF 瓷片电容直接插在 DIP 12/13 脚**，最好 37/36 脚也插一个；另加 10µF |
| CE#/WE#/RE# 上拉 | 理论上 FPGA 配置期间可能误操作，实际风险极低（需凑出完整命令序列） | FPGA 内部上拉；外接 10k 更稳 |
| 串联电阻 | 低速下无影响 | 不加 |

**保护数据的技巧**：只做读取实验时把 **WP#（19 脚）接 GND**，芯片会拒绝一切编程/擦除命令。

## 5. 起步时序（27MHz 系统时钟，1 周期 ≈ 37ns）

先放慢，确认正确后再提速：

| 参数 | 起步值 |
|---|---|
| WE# / RE# 低电平宽度 | 3 周期（≈111ns） |
| WE# / RE# 高电平宽度 | 3 周期 |
| CLE/ALE/CE# 建立时间 | 2 周期 |
| 读数据采样点 | RE# 拉低后第 3 周期末（RE# 上升前） |
| 命令后等 R/B# 前的延迟（tWB） | ≥ 3 周期（≥100ns） |

## 6. 首次测试：读 ID

建议第一步用**纯 Verilog 状态机**（不上软核），结果从板载串口打印十六进制：

1. 上电，等待 ≥1ms；
2. 命令 `FF`（复位），等 R/B# 变高（或延时 ≥1ms）；
3. 命令 `90`，地址 `00`；
4. 连续读 5 字节，串口输出。

**期望：第 1 字节为 `0xEF`（华邦厂商代码）**，其余字节对照数据手册的设备 ID。
进阶：命令 `90` + 地址 `20` 读 4 字节，应为 ASCII `"ONFI"`（若芯片支持 ONFI）；然后 `EC` + `00` 读 256 字节参数页。

### 逻辑分析仪通道建议

| 通道 | 信号 |
|---|---|
| CH0 | CLE |
| CH1 | ALE |
| CH2 | WE# |
| CH3 | RE# |
| CH4 | CE# |
| CH5 | R/B# |
| CH6 | IO0 |
| CH7 | IO1 |

24MHz 采样（约 41ns 分辨率）足以观察放慢后的时序。Mac 上用 PulseView。

## 7. 排错清单

| 现象 | 可能原因 |
|---|---|
| 读回全 `FF` | CE# 没拉低；VCC 未接；RE# 时序过快；采样点太早；芯片放反或未压紧 |
| 读回全 `00` | 数据线短路到地；VCC 未上电 |
| 数据位错乱、字节固定错位 | IO 线接错顺序（核对 29–32、41–44 脚） |
| 偶发错误 | 没有去耦电容；地线太少；杜邦线过长；时序太紧 |
| R/B# 一直为低 | 芯片忙（未完成复位）；接错脚；芯片损坏 |
| R/B# 一直为高但操作失败 | 正常的“就绪”；检查状态寄存器（`70`）bit0 FAIL、bit7 WP# |
| 写入/擦除无效 | WP# 为低（写保护）；状态寄存器 bit7 为 0 即表示受保护 |
