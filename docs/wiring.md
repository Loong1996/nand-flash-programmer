# 接线指南（Tang Nano 9K，全部封装）

所有转接座**同时**接在 Tang Nano 9K 上，换芯片不用改线：

- **TSOP48 翻盖座**：并口 NAND（以及通过转接板的 BGA63/BGA48 NAND）
- **SOP8 / WSON8 / DIP8 / USON8 座或 SOP8 测试夹**：SPI NOR / SPI NAND（这些封装引脚定义相同，可以并联到同一组线上）
- **SOIC16 座**：16 脚 SPI Flash（如 MX25L25635F SOIC16、W25N01GV SFIG）
- **FT232H 模块**（可选，高速通道）

> ⚠️ **只支持 3.3V 芯片**。Tang Nano 9K 排针是 3.3V 电平。1.8V 芯片（型号常带 Z、W、U、LQ、1.8V 字样）需要另做电平转换转接板，否则会损坏芯片。上位机遇到数据库里标注 1.8V 的芯片会拒绝操作。
>
> ⚠️ **换芯片前先拔掉 USB 线**（断电），再打开翻盖座或夹上测试夹。

## 0. Tang Nano 9K 排针

下表“FPGA 脚”是 FPGA 封装引脚号，Tang Nano 9K 排针旁的丝印标的就是这个号码，按丝印数字接线即可。如果你的板子丝印不同，以 Sipeed 官方引脚图为准。
**电源用排针上的 3V3 和 GND，不要用 5V。**

| 用途 | FPGA 脚 |
|---|---|
| 并口 NAND | 25 26 27 28 29 30 31 32 · 69 70 71 72 73 74 · 49 |
| SPI Flash | 39 63 75 77 76 48 |
| FT232H | 41 42 51 53 54 55 56 57 · 33 34 38 40 · 35 36 37 |
| 空闲 | 68 |
| **不能用**（1.8V bank 3） | 79 80 81 82 83 84 85 86 |

> ⚠️ **79–86 脚是 1.8V**（和板载 LED、按键同属 bank 3），不能接 3.3V 的 Flash。本项目早期版本的接线表把 NAND 控制线和 SPI DI 放在了 79–85，已经改到 69–75；如果照旧表接过线，请按本表改接。
>
> 68–75 同时连到板载 HDMI 座和 LCD 排线座：用编程器时**不要插 HDMI 线和屏幕**。

板载 LED（从 FPGA 引脚 10 到 16）：

| LED | 含义 |
|---|---|
| LED0 | 心跳，约 1.6 Hz 闪烁 = 固件在运行 |
| LED1 | 串口有数据 |
| LED2 | FT232H 有数据 |
| LED3 | 并口 NAND 总线活动 |
| LED4 | SPI 总线活动 |
| LED5 | 出错（协议错误、超时中止、串口溢出；读取 INFO 后清除） |

按键 S1 = 复位引擎（中止一切操作，恢复默认设置）。

## 1. TSOP48 并口 NAND（8 位）

TSOP48 转 DIP48 翻盖座：DIP 第 n 脚 = TSOP 第 n 脚（**到手先用万用表逐脚量通断**，并认清座子上的 1 脚标记：芯片圆点 / 缺角对准座子 1 脚）。

| 信号 | TSOP48 脚 | FPGA 脚 | 说明 |
|---|---|---|---|
| R/B# | 7 | 49 | 开漏，FPGA 内部已上拉；建议再加 10 kΩ 到 3V3 |
| RE# | 8 | 73 | |
| CE# | 9 | 74 | |
| VCC | 12 | 3V3 | |
| VSS | 13 | GND | |
| CLE | 16 | 70 | |
| ALE | 17 | 71 | |
| WE# | 18 | 72 | |
| WP# | 19 | 69 | FPGA 默认拉低（写保护），只在编程/擦除时拉高 |
| IO0 | 29 | 25 | |
| IO1 | 30 | 26 | |
| IO2 | 31 | 27 | |
| IO3 | 32 | 28 | |
| VSS | 36 | GND | 两个 VSS 都要接 |
| VCC | 37 | 3V3 | 两个 VCC 都要接 |
| IO4 | 41 | 29 | |
| IO5 | 42 | 30 | |
| IO6 | 43 | 31 | |
| IO7 | 44 | 32 | |
| 其余 | — | 不接 | 多片选芯片的 CE2#（10 脚）、R/B2#（6 脚）悬空即可，只访问第一个 die |

**去耦电容（必须）**：在转接座上直接插 100 nF 瓷片电容：12↔13 脚一个，37↔36 脚一个；另在 3V3–GND 之间加一个 10 µF。

**BGA63 / BGA48 NAND**：用成品 “BGA63 转 TSOP48” 转接板插在翻盖座上，接线不变。

**不支持**：16 位 NAND（x16）、TSOP48 并口 NOR（如 S29GL、MX29LV，协议不同）、eMMC。

## 2. SPI Flash：SOP8 / WSON8 / DIP8 / USON8 / 测试夹

这几种封装引脚定义完全相同，可以把 SOP8 座、WSON8 座、测试夹的同名引脚**并联**到同一组线上（同一时间只放一颗芯片）。

| 芯片脚 | 信号 | FPGA 脚 | 说明 |
|---|---|---|---|
| 1 | CS# | 39 | |
| 2 | DO (IO1) | 77 | |
| 3 | WP# (IO2) | 76 | FPGA 输出高电平（四线读时作 IO2 输入） |
| 4 | GND | GND | |
| 5 | DI (IO0) | 75 | 四线读时 FPGA 会暂时释放这根线 |
| 6 | CLK | 63 | |
| 7 | HOLD# / RESET# (IO3) | 48 | FPGA 输出高电平（四线读时作 IO3 输入） |
| 8 | VCC | 3V3 | 旁边加 100 nF 电容到 GND |

**测试夹在板读写注意**：
- 目标板**不要**单独上电，由编程器的 3V3 供电。
- 如果目标板上的主控会干扰 SPI 总线（读出 ID 不稳定），需要让主控保持复位，或者把 Flash 焊下来。
- 夹子线尽量短，速度用 `--spi-mhz 2` 起步。

| 芯片脚 | 信号 | FPGA 脚 |
|---|---|---|
| 1 | HOLD# / IO3 | 48 |
| 2 | VCC | 3V3 |
| 7 | CS# | 39 |
| 8 | DO / IO1 | 77 |
| 9 | WP# / IO2 | 76 |
| 10 | GND | GND |
| 15 | DI / IO0 | 75 |

| 3–6、11–14 | NC | 不接 |

SOIC16 座和 8 脚座可以同时接在同一组 FPGA 脚上（同一时间只放一颗芯片）。

## 4. FT232H 模块（可选，高速）

先完成 EEPROM 设置（见 [quickstart.md](quickstart.md) 第 6 步），**设置完成之前不要把 FT232H 的 AD/AC 引脚接到 FPGA**。

接线按 **245 同步 FIFO** 的要求一次接全，两种模式都能用：

- `--port ft232h`：异步 FIFO，约 2 MB/s，最稳；
- `--port ft232h-sync`：同步 FIFO，FT232H 输出 60 MHz CLKOUT，固件自动切换到同步桥，仿真中 NAND 读约 13–17 MB/s（实物未验证）。第一次用先跑 `nsprog -p ft232h-sync ft232h-tune` 调时钟相位（固件 1.3），可用窗口太窄或仍出错就改回异步。

异步模式下 CLKOUT 没有信号，FPGA 不驱动 OE#（悬空由上拉保持高电平）。

| FT232H 脚 | 信号 | FPGA 脚 | 说明 |
|---|---|---|---|
| AD0 | D0 | 41 | |
| AD1 | D1 | 42 | |
| AD2 | D2 | 51 | |
| AD3 | D3 | 53 | |
| AD4 | D4 | 54 | |
| AD5 | D5 | 55 | |
| AD6 | D6 | 56 | |
| AD7 | D7 | 57 | |
| AC0 | RXF# | 33 | |
| AC1 | TXE# | 34 | |
| AC2 | RD# | 40 | |
| AC3 | WR# | 38 | |
| AC4 | SIWU# | 35 | 另加 10 kΩ 上拉到 FT232H 模块的 3.3V |
| AC5 | CLKOUT | 36 | 全局时钟脚；这根线尽量短 |
| AC6 | OE# | 37 | 同步模式下由 FPGA 驱动；建议加 10 kΩ 上拉到 3.3V |
| GND | GND | GND | 必须共地，建议接两根 |

- FT232H 模块自己用 USB 供电，**不要**把它的 3.3V/5V 接到 Tang Nano 9K。
- 数据线尽量短（10 cm 以内），CLKOUT 尤其要短。
- `nsprog pins` 会显示 CLKOUT、OE#、SIWU# 的状态：异步模式下 CLKOUT 为 idle 是正常的，OE# 和 SIWU# 应为高电平；用 `--port ft232h-sync` 连接时 CLKOUT 应为 active。
- 接好后 Tang Nano 9K 和 FT232H 两根 USB 线都插到电脑上；上位机自动优先使用 FT232H。

## 5. 同时接好后的检查

1. 不放任何芯片，插上 USB，运行 `nsprog pins`：
   - `NAND R/B#` 应为 high；
   - `NAND IO[7:0]` 应为 `11111111`。有某位是 0，说明那根数据线短路到地或接错。
2. `nsprog info` 应显示“parallel NAND: no chip”和“SPI: no chip”。
3. 断电，放入芯片，再运行 `nsprog info`。
