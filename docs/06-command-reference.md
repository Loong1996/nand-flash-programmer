# 06 命令速查

具体芯片以数据手册为准。

## 1. 并口 NAND（ONFI / JEDEC 常用命令）

| 操作 | 序列 | 说明 |
|---|---|---|
| 复位 | `FF` → 等 R/B# | 上电后第一条命令 |
| 读 ID | `90` + 地址 `00` → 读 5 字节 | 第 1 字节厂商码（华邦 `0xEF`、三星 `0xEC`、东芝/铠侠 `0x98`、美光 `0x2C`、海力士 `0xAD`、旺宏 `0xC2`） |
| ONFI 签名 | `90` + 地址 `20` → 读 4 字节 | 应为 `"ONFI"` |
| 读参数页 | `EC` + 地址 `00` → 等 R/B# → 读 256 字节（通常有多份冗余拷贝） | 页大小、spare 大小、每块页数、块数、地址周期、ECC 要求、时序模式；含 CRC |
| 读页 | `00` + 列地址(2) + 行地址(2–3) + `30` → 等 R/B# → 连续读 | 可读含 OOB 的整页 |
| 页内随机读 | `05` + 列地址(2) + `E0` → 读 | 跳到页内其他列（如读 OOB） |
| 编程页 | `80` + 列(2) + 行(2–3) + 数据… + `10` → 等 R/B# → `70` 查状态 | |
| 页内随机写 | `85` + 列(2) + 数据… | 在 `80` 与 `10` 之间使用 |
| 擦除块 | `60` + 行地址(2–3) + `D0` → 等 R/B# → `70` 查状态 | 行地址中页号部分忽略 |
| 读状态 | `70` → 读 1 字节 | 见下表 |

状态寄存器（`70`）：

| 位 | 含义 |
|---|---|
| bit0 | FAIL：1 = 上次编程/擦除失败 |
| bit6 | RDY：1 = 就绪（可替代 R/B#） |
| bit7 | WP#：0 = 写保护中 |

地址周期：列地址 2 字节（页内字节偏移，含 spare）；行地址 2–3 字节（块号 + 页号）。2Gb 级 SLC 通常共 5 个地址周期。

## 2. SPI NOR

| 命令 | 功能 |
|---|---|
| `9F` | JEDEC ID（厂商 + 类型 + 容量） |
| `5A` | 读 SFDP（3 字节地址 + 1 dummy） |
| `03` / `0B` | 读 / 快速读（`0B` 带 1 dummy 字节） |
| `3B` / `6B` | Dual / Quad 输出读（1-1-2 / 1-1-4，8 个空时钟） |
| `BB` / `EB` | Dual / Quad IO 读（1-2-2 / 1-4-4，地址和模式字节也走多线；空时钟数见 SFDP） |
| `32` | 四线页编程（1-1-4，需 QE） |
| `06` / `04` | 写使能 / 写禁止 |
| `05` / `35` / `15` | 读状态寄存器 1 / 2 / 3 |
| `01` / `31` / `11` | 写状态寄存器 1 / 2 / 3 |
| `02` | 页编程（≤256 字节，不跨页） |
| `20` / `52` / `D8` | 擦除 4KB / 32KB / 64KB |
| `C7` 或 `60` | 整片擦除 |
| `B7` / `E9` | 进入 / 退出 4 字节地址模式（>16MB） |
| `AB` / `B9` | 唤醒 / 掉电 |
| `66` + `99` | 软件复位 |

注意：状态寄存器 BP 位（块保护）、SRP 位、QE 位（Quad 使能）；编程前需 `06`；忙等待查 SR1 bit0（WIP/BUSY）。

## 3. SPI NAND（以 W25N / GD5F 为例）

| 命令 | 功能 |
|---|---|
| `FF` | 复位 |
| `9F` | 读 ID（通常需 1 dummy 字节） |
| `0F` + 地址 | Get Feature（读特性寄存器） |
| `1F` + 地址 + 值 | Set Feature |
| `13` + 页地址(3) | 页读到 cache（Page Data Read），然后轮询忙 |
| `03` / `0B` + 列地址(2) + dummy | 从 cache 读出 |
| `06` | 写使能 |
| `02` + 列地址(2) + 数据 | 装载数据到 cache（清空其余部分） |
| `84` + 列地址(2) + 数据 | 随机装载（不清空） |
| `32` / `34` + 列地址(2) + 数据 | 四线装载 / 四线随机装载（需 QE，特性寄存器 `B0` bit0） |
| `3B` / `6B` + 列地址(2) + dummy | 双线 / 四线从 cache 读出 |
| `BB` / `EB` + 列地址 + 4 个空时钟 | 地址也走双线 / 四线 |
| `10` + 页地址(3) | 执行编程（Program Execute） |
| `D8` + 页地址(3) | 擦除块 |

特性寄存器（地址因厂商略有不同，常见）：

| 地址 | 名称 | 常用位 |
|---|---|---|
| `A0` | 保护寄存器 | BP 位；**上电默认常为全保护，编程前需写 `00` 解锁** |
| `B0` | 配置寄存器 | ECC_EN（片上 ECC 开关）、BUF 模式（W25N） |
| `C0` | 状态寄存器 | OIP/BUSY、WEL、E_FAIL、P_FAIL、ECC 状态位 |

## 4. 坏块与 ECC 要点

- **出厂坏块标记**：大页 SLC NAND 通常在每块第 1 页（有的还包括第 2 页或最后一页）的 spare 区第 1 字节，非 `0xFF` 即坏块。具体位置以手册为准。
- **永远不要擦除出厂坏块**：擦除会清除标记，坏块信息将永久丢失。擦除/编程前先扫描建立坏块表。
- 编程/擦除失败（状态 bit0=1）的块应标记为使用中产生的坏块。
- **Raw 模式**：读写完整页 + OOB，不做任何 ECC 处理 —— 编程器固件只提供此模式。
- **ECC 布局由目标 SoC 决定**（BCH 位数、每扇区大小、OOB 中 ECC 字节位置），PC 端按目标布局计算和校验。
- SPI NAND 的片上 ECC：dump 原始数据时应关闭（`B0` 寄存器 ECC_EN=0），为目标设备写镜像时按设备使用方式决定。
- 常见“跳过坏块”写法：遇坏块顺延到下一好块（与 Linux MTD/U-Boot `nand write` 行为一致）；另一种是保持物理地址一一对应（raw 镜像克隆）。上位机需同时支持。
