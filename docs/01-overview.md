# 01 方案总览

## 1. 三类目标芯片

| 类型 | 接口 | 引脚数 | 主要难点 |
|---|---|---|---|
| SPI NOR（如 W25Q 系列） | SPI / Dual / Quad | 6–8 | 简单；可用 SFDP 自动识别；>16MB 需 4 字节地址；状态寄存器保护位、QE 位 |
| SPI NAND（如 W25N、GD5F） | SPI | 6–8 | 两段式读写（经过 cache）；片上 ECC 开关；块保护寄存器；坏块 |
| 并口 NAND（TSOP48 / BGA63 等） | 8/16 位总线 + CLE/ALE/WE#/RE#/CE#/R/B#/WP# | 约 15–24 | 总线时序、OOB（spare 区）、ECC 布局、坏块、1.8V 芯片 |

## 2. 编程器中的“两层协议”

```
[PC 上位机] ←—— 第①层 ——→ [编程器] ←—— 第②层 ——→ [Flash 芯片]
```

- **第②层：编程器 ↔ 芯片** —— 标准的（ONFI/JEDEC），所有编程器都一样。
  例：并口 NAND `90` 读 ID、`00…30` 读页、`60…D0` 擦块；SPI `9F` 读 ID、`03` 读数据。
- **第①层：PC ↔ 编程器** —— 各家自定义。

| 编程器 | 第①层 |
|---|---|
| NANDO（bbogush/nand_programmer） | 项目自定义命令包（定义在 `qt/cmd.h` 及固件），走 USB CDC 虚拟串口 |
| flashrom + serprog 设备 | serprog 公开协议（仅 SPI） |
| CH341A | 沁恒私有 USB 协议 |
| T48 / RT809H 等商业编程器 | 私有 |
| 市售“NAND 编程器 4.1”板 | 未知（闭源），见 [02 文档](02-nando-and-market-boards.md) |

> “NANDO” 是**项目名**（NAND Open programmer），不是行业标准协议。文中“NANDO 协议”指该项目自定义的第①层命令格式。

## 3. 主控方案对比

| 方案 | 优点 | 缺点 | 适合 |
|---|---|---|---|
| A. STM32F103 + FSMC | FSMC 自带 NAND 控制器 + 硬件 ECC；可直接复用 NANDO 固件与上位机 | USB 全速约 1MB/s；只支持 3.3V（除非加电平转换） | 最快做出能用的东西 |
| B. CH32V307 | 有 FSMC；**内置 USB 2.0 高速 PHY**；便宜 | 需移植固件；FSMC 是否支持 NAND bank 待查手册（不支持也可用 A16/A17 当 CLE/ALE 的方式驱动） | 性价比 + 速度 |
| C. RP2040/RP2350 + PIO | PIO 可精确模拟任意时序；便宜 | USB 全速；并口 NAND 需自写 PIO | 灵活折腾 |
| D. FT2232H/FT232H 直驱 | SPI 直接被 flashrom 支持；MCU Host Bus 模式可驱动并口 NAND | 依赖 PC，效率一般 | 只要“读取工具” |
| **E. FPGA** | 时序完全可控；**I/O bank 电压可调，免电平转换**；可并行/16 位/硬件 ECC | 开发量约为 MCU 的 3–5 倍；需高速 USB 桥才能发挥 | 高速、学习 FPGA、BGA/多片 |

## 4. 速度分析（瓶颈在哪里）

| 环节 | 实际速度 |
|---|---|
| USB 串口（开发板板载） | 约 0.1–0.3 MB/s |
| USB 全速（MCU 方案，如 NANDO） | 约 1 MB/s（读 1GB ≈ 17 分钟） |
| USB 高速（CH32V307 / FT232H 同步 FIFO） | 十几 ~ 约 40 MB/s |
| USB3（FT601 / FX3） | 100+ MB/s |
| NAND 读（异步模式） | 约 20–40 MB/s |
| NAND 写 | 约 5–15 MB/s（受 tPROG 200–600µs/页限制） |
| SPI NOR 写 | 约 0.5–1 MB/s（芯片决定） |

结论：
- **写入速度主要由芯片决定**，FPGA 主要加速“读”；
- FPGA 必须配高速 USB 通道（FT232H 等），否则速度被 USB 全速卡死；
- ECC 放在 PC 端计算已经足够快，硬件 ECC 不是刚需。

## 5. 通用硬件设计要点

1. **电压**：芯片侧 VCC/VCCQ 可选 1.8V / 3.3V，带开关与限流。MCU 方案需双电源电平转换（推荐 SN74AVC8T245 类带方向控制的器件，**不要**用 TXS0108E 类自动方向器件驱动并行总线）；FPGA 方案可直接用独立 VCCIO 的 bank。
2. **R/B#** 为开漏，必须上拉；**WP#** 可控；数据线可串 22–33Ω 电阻。
3. **转接座子板化**：TSOP48 翻盖座、SOP8（150/208mil）、WSON8、SOIC16、测试夹。
4. **目标芯片电源可控**：换芯片无需拔 USB。

## 6. 通用固件/软件原则

- 固件只做 **Raw 读写（含 OOB）**，ECC 与坏块策略放 PC 端 —— 不同 SoC 的 ECC 布局不同，要兼容目标设备必须按其布局处理。
- **永远不要擦除出厂坏块标记**；擦除前先扫描建立坏块表。
- 芯片参数优先用 ONFI 参数页（`EC`）/ SFDP 自动识别，辅以芯片数据库。
- USB 数据通道用双缓冲，边传边编程。
