## 第二阶段：USB 高速通道

| # | 物品 | 数量 | 购买要点 | 大约价格 |
|---|---|---|---|---|
| 12 | **FT232H 模块**（如 CJMCU-FT232H） | 1 | **必须带 EEPROM**（93C46/93C56 等 8 脚小芯片）；引出 AD0–AD7、AC0–AC9 全部引脚。备选 FT2232H 小板 | ¥30–60 |

## 免费软件（macOS）

| 软件 | 用途 | 安装 |
|---|---|---|
| oss-cad-suite | Yosys、nextpnr、Apicula（高云）、openFPGALoader | 官网下载 macOS 版解压即用 |
| LiteX | 软核 SoC 生成 | `pip` / 官方 `litex_setup.py` |
| PulseView | 逻辑分析仪上位机 | sigrok 官网 |
| libftdi、flashrom | FT232H 访问、SPI NOR 读写 | `brew install libftdi flashrom` |
| Python 3（pyserial、pyftdi 等） | 上位机 | 系统自带或 `brew install python` |

## 建议购买顺序

1. 先买第一阶段 1–11 项（约 ¥200），完成“读 ID 读到 `0xEF`”；
2. 再买 FT232H（第二阶段）；
3. 最后买 SPI 相关（第三阶段）。
